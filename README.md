# Python Beginner Practice

**Small experiments for understanding Python one concept at a time.**

A personal learning notebook with notes and examples for common Python language features. The material records practice rather than presenting a packaged application or a polished course.

## Topics in the notebook

- Lists, slicing, sorting, and common collection operations.
- Tuples, dictionaries, and sets.
- Functions, parameters, and variable scope.
- Iteration, ranges, and enumeration.
- Imports and examples using the standard library.

## Open the material

Read [`practice note.ipynb`](<practice note.ipynb>) directly on GitHub, or use Jupyter locally:

```bash
python -m venv .venv
source .venv/bin/activate
pip install jupyter
jupyter notebook
```

Open the notebook and work through a topic cell by cell. There is no project-specific application server or package to install.

## How to use the exercises

Predict an example's result before executing it, then change its inputs and inspect the output. Compare mutable collections with immutable values and trace the scope of function variables.

Some cells are unfinished notes or deliberately exploratory fragments, including references to modules that are not supplied. Review and adapt cells individually rather than expecting **Run All** to complete without edits.

## Repository structure

The repository contains one practice notebook and a Git ignore file. Keep new examples organized under clear topic headings when extending the notes.
